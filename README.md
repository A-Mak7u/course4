## 1. Проект

- Температурная модель по метеостанциям на базе `ERA5 + MODIS + XGBoost`
- Основной код: `xgb/`, `analysis/`, `transfer/`
- Основные экспериментальные артефакты: `outputs_runs/`

---

## 2. Отчёты

- Саратовская ветка: `reports/saratov.md`
- Волгоградская ветка: `reports/volgograd.md`

---

## 3. Структура

- `xgb/` — основная саратовская линия обучения и инференса
- `transfer/` — переносимость по регионам, сборка новых датасетов, bridge/transfer-эксперименты
- `analysis/` — EDA, SHAP, линейные baseline-диагностики
- `eda_plots/` — подтверждённые графики по саратовскому датасету
- `outputs_runs/` — сохранённые run-bundles с метриками, графиками и конфигами

---
